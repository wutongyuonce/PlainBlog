# PlainBlog — 权威规格

状态：本地实现、自动检查及 Chromium 浏览器验收已完成。独立双轴审查及修正证据保存在 docs/reviews；实测范围与限制见 VERIFICATION。用户授权采用推荐决策，无需逐项采访。

本文是产品行为、范围与验收的唯一权威。README 只作操作入口，CONTEXT 只定义术语，ARCHITECTURE 只描述当前实现，ADR 保存决策理由，reviews 保存审查证据。实现发生变化时先判断是否改变契约，再在同一改动同步本文及受影响文档，不能靠代码注释暗改需求。

## 问题与方案

希望有一个接近 Hyoban 阅读密度的黑色极简个人博客，以无背景框的面包屑和按需出现的下拉导航代替常驻导航栏。原型 A 被选中，但胶囊、过松留白和重复的 Blog 汇总页被否决。

采用独立项目，不迁移或修改现有 YuBlog。新项目在 `/Users/a/Desktop/WorkSpace/我的Github项目/PlainBlog`。仅本地 Git 提交，不创建远端、不部署、不复制参考博客文章。

## 场景与用户故事

1. 读者打开 Home，看一段作者介绍和按年份排列的全部公开文章，不需要先选栏目。
2. 读者点击文章标题，进入稳定的正文 URL；直接访问、刷新和浏览器返回均成立。
3. 读者看到 `Home / Blog / 文章标题`；Blog 仅是路径分类标签，没有链接、按钮、下拉或假跳转。
4. 读者点击 Home 回到首页；点击它旁边的小箭头展开站点目录，两种动作分开。
5. 读者在任意页面从同一个目录跳转 Home、Projects、About。不存在另一个 Blog 汇总入口。
6. 键盘读者能 Tab 到目录开关、Enter/Space 展开、Tab 访问链接；Esc 关闭并还焦点，点击外部或焦点移出也关闭（增强脚本可用时）。
7. 无 JavaScript 时，读者仍能展开原生目录、访问全部页面、阅读完整文章。
8. 手机读者可阅读长文章标题、长链接、宽代码和表格，不造成整页横向滚动；代码和表格可局部滚动。
9. 作者新增一篇 Markdown、填写标题与日期即可出现在首页和独立正文页，无需手改路由或列表。
10. 作者将文章标记 draft 后，它既不出现在首页，也不生成可访问正文文件。
11. 作者维护 Projects、About 的 Markdown，继续使用与正文一致的排版，无需组件知识。
12. 作者只需修改站点配置与内容，不必维护前端框架、客户端状态或一套渲染插件。
13. 读者遇到无效地址时看到简洁 404 和首页链接，不会落入伪造内容或空白页面。
14. 新维护者可按文档安装、运行、构建、添加文章和部署静态产物；文档与实际命令一致。

## 规则与不变量

| ID | 契约 |
| --- | --- |
| R1 | 页面为 `/`、`/blog/<slug>/`、`/projects/`、`/about/`，另有技术性 404。不存在 `/blog/` 汇总、Index、Notes、分类页或旧原型入口。 |
| R2 | 站点目录仅三个真实入口 Home、Projects、About。页面入口来自单一配置；新增页面可加入配置而无需重做导航。 |
| R3 | 面包屑无常驻背景、描边、胶囊、阴影或分隔线容器；普通灰白文字、小 Home 图标、斜线与细箭头。只有展开的目录有必要的深色浮层和细边界。当前页更亮。 |
| R4 | Article 路径固定 `Home / Blog / title`；Blog 为静态文本。Projects/About 当前标签不链接。窄屏可以省略路径中的长标题，但正文 h1 完整呈现。 |
| R5 | Home 介绍在前，全量公开文章按日期降序、按年降序分组；同日以稳定 slug 顺序打破平局。只显示标题、右侧 MM/DD，不加摘要、卡片、封面、分类。 |
| R6 | 标题必填且非空；日期是有效的 YYYY-MM-DD 日历日，不接受自动纠正的无效日期。使用日期字符串的日历语义，不能因运行时区换年或换日。draft 默认 false；true 时全站排除。没有定时发布功能，未来日期但未标 draft 仍公开。 |
| R7 | slug 由内容文件名产生，使用小写 ASCII kebab-case；仅一层文章文件，不引入任意 URL 或标题自动更名机制；重复/不合法数据必须在构建时明确失败，不能悄悄产出冲突页面。 |
| R8 | 本地 Markdown 经构建期渲染，支持段落、H2–H6、列表/嵌套列表、强调、引用、链接、代码围栏/语法高亮、行内代码、图片、水平线、GFM 表格/任务列表/删除线。文档标题由 frontmatter 生成，正文从 H2 起。不要求数学、MDX、图表或自定义 callout。 |
| R9 | 全站静态 HTML、CSS，只有目录渐进增强需要少量浏览器脚本。不使用 React、客户端路由、Tailwind、UI 库、运行时 Markdown、CMS、数据库、外部字体、追踪或远程运行时请求。 |
| R10 | 最小语义和可访问性：lang=zh-CN、唯一 h1、main、跳过导航链接、面包屑语义和当前页标识、可见键盘焦点；所有交互可键盘操作，不能仅 hover 才出现。链接可辨认。 |
| R11 | 每页有独立标题、description。站点 URL 未配置时不输出假域名 canonical/OG URL；配置有效生产绝对 HTTP(S) 地址后使用对应 URL。不要求 RSS/sitemap/评论/搜索/主题切换。 |
| R12 | 初始文章为原创示例，不声称是用户真实经历。至少跨两年并有一篇涵盖 Markdown 能力的示例，含本地图片、长代码、长链接及表格；有草稿样本用于验证不会发布。 |

## 视觉契约

参考来源：[Hyoban 首页](https://hyoban.cc)、[正文实例](https://hyoban.cc/folo-database)、[Astryx Breadcrumb Item](https://astryx.atmeta.com/components/BreadcrumbItem)。仅参考布局与渲染风格，不复制站点内容或代码包。

实测基准（浏览器 CSS pixels）：

| 项目 | 目标 |
| --- | --- |
| 背景 / 正文亮色 / 次要文字 | `#111110` / `#eeeeec` / `#b5b3ad` |
| 字体 | 系统 sans-serif，年份与日期用系统 monospace；不额外下载字体 |
| 内容宽度 | 最大 65ch，在实测系统字体下约 655px；窄屏左右各 16px |
| 页面顶部 | 32px；新增面包屑的交互高度约 32px，与内容间距 24px，不沿用原型的 60px 顶部和 57px 空白 |
| 首页与页面标题 | 16px / 24px，常规字重，不使用放大 hero |
| 简介 | 16px / 24px，段间 12px，介绍与年份列表间 40px |
| 年份文章 | 16px / 24px；年份到列表 12px；行间 12px；年份组间 32px；日期右对齐 |
| Markdown | 16px / 28px；段落上下 20px；标题保持 16px、600 字重、1.3 行高、上 32px / 下 8px |
| Markdown 代码 | 14px 系统 monospace；围栏内边距 16px、上下 24px，深色 Shiki 高亮；不加复制/行号工具栏 |
| Markdown 列表 | 上下 20px、左缩进 24px；引用细左线；表格和代码独立横向滚动 |

排版密度与参考保持一致，但面包屑和内容不同，不能要求整页截图像素完全重合。无背景框限制针对面包屑，不禁止代码块、行内代码或展开目录具有功能性底色。页面不添加装饰性页脚口号、动效、边栏、背景特效。

## 失败、资源与信任

- 内容由仓库作者维护，是可信源，不提供访客 HTML 输入；不声称具备不可信 Markdown 隔离能力。
- 无效 frontmatter、日期、slug 或缺失本地图片导致构建失败，错误必须能定位内容文件；不静默跳过。
- 零篇公开文章时首页显示明确的空列表说明，同时仍显示简介和目录。
- 无登录、表单写入、服务端状态或网络并发问题。默认不做分页，适用于个人博客规模（数百篇）；不承诺无限列表性能。
- 最少 JavaScript，无持久化导航状态；全页面跳转使用浏览器自身历史恢复。
- 不安装系统包、不更改用户全局配置、不进行远端发布。

## 实现与测试决策

采用 Astro 静态生成、内容集合校验、内置 Markdown/GFM/Shiki 与手写 CSS。原生 details/summary 是目录开闭的权威状态，增强脚本不另外维护一份状态。

预先选定的测试 seam：

1. **内容发布选择的公开 interface**：日期校验、draft 排除、稳定排序。少量 Node 原生测试，不 mock 内部实现。
2. **最终静态站点输出**：读取构建 HTML 验证页面/路由、文档元信息、草稿不发布、Blog 无链接、Markdown 语义和本地资源；不以源代码字符串断言替代行为测试。
3. **实际浏览器**：目录鼠标/键盘/无JS、返回、宽屏与 320/390px、长内容的局部滚动和视觉密度。

先失败再实现，每个切片只覆盖当下义务。测试应验证可观察结果，不测试 CSS 源文件包含某段代码、不用巨型快照或冗余实现层测试。

## 非目标

不迁移现有 YuBlog，不做 Blog 汇总、分类/标签、目录索引页、RSS、sitemap、搜索、评论、主题切换、编辑后台、客户端状态框架、旧链接重定向、MDX、公式或复杂插件系统。没有发布授权，因此只完成本地项目、Git 提交与预览。
